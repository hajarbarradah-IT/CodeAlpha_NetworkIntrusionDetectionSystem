# CodeAlpha - Network Intrusion Detection System

## 📌 Description
Implementation of a network-based Intrusion Detection System (IDS) using Suricata, developed as part of the CodeAlpha Virtual Internship in Cybersecurity (Task 4).

## 🛠 Technologies Used
- Suricata 7.0.3
- WSL2 (Ubuntu 24.04)
- Custom detection rules

## 📂 Repository Contents
- `suricata.yaml` — configuration file used (network interface, enabled rules)
- `eve.json` — extract of logs generated by Suricata during detection
- `screenshots/` — screenshots illustrating the setup (installation, configuration, detected alerts)
- `scripts/suricata-respond.sh` — automated response script triggered on alert detection

## ⚙️ How It Works
1. Installed Suricata on WSL2 (Ubuntu)
2. Configured the network interface to monitor (`eth0`)
3. Created a custom detection rule
4. Launched Suricata as a continuous monitoring service
5. Tested with real network traffic and verified alerts in the logs
6. Implemented an automated response script triggered by detected alerts

## 🎓 What This Project Demonstrates
- Understanding of how an IDS works
- Configuration of a real-world security tool used in enterprise SOCs (Security Operations Centers)
- Writing custom detection rules
- Troubleshooting real technical issues (configuration conflicts, systemd service management)
